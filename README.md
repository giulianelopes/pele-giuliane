# 💎 Pele Giuliane

App pessoal de skincare focado em:
- estímulo de colágeno
- firmeza da pele
- rotina estruturada com LED, retinoide e ativos

## 📱 Acessar o app

https://giulianelopes.github.io/pele-giuliane/

## 🚀 Funcionalidades

- checklist diário de manhã e noite
- modo pele sensível
- rotina inteligente por dia da semana
- versão mobile e desktop
- ícone personalizado para tela inicial do iPhone

## 📂 Arquivos principais

- `index.html` — versão mobile/app para iPhone
- `desktop.html` — versão desktop/MacBook
- `manifest.json` — configuração do app web
- `apple-touch-icon.png` — ícone para iPhone
- `icon-512.png` — ícone padrão do app

## 🌐 Como publicar no GitHub Pages

Suba todos os arquivos deste pacote na raiz do repositório `pele-giuliane`.

Depois acesse:

https://giulianelopes.github.io/pele-giuliane/

No iPhone:
1. abra o link no Safari;
2. toque em Compartilhar;
3. escolha Adicionar à Tela de Início.
