# 💎 Pele Giuliane

App pessoal de skincare focado em organização de rotina, estímulo de colágeno, firmeza da pele e envelhecimento saudável.

## 📱 Acessar o app

https://giulianelopes.github.io/pele-giuliane/

## 🚀 Funcionalidades

- Checklist diário de manhã e noite
- Rotina estruturada por dia da semana
- Aba de produtos com filtros por categoria
- Aba de dicas com orientações de uso, cuidados e alertas
- Modo pele sensível
- Progresso diário da rotina
- Ícone personalizado para tela inicial do iPhone
- Layout otimizado para celular

## 🧴 Estrutura da rotina

A rotina organiza os cuidados em três eixos principais:

1. **Manhã**
   - Tônico
   - Vitamina C
   - Medicube
   - Protetor solar

2. **Noite**
   - Alternância entre LED + peptídeos de cobre
   - Retinoide
   - Azelan
   - Cicaplast/barreira cutânea conforme necessidade

3. **Dicas**
   - O que fazer
   - O que não fazer
   - Mindset para consistência e resultados

## 📂 Arquivos principais

- `index.html` — app principal mobile otimizado
- `manifest.json` — configuração do app web
- `apple-touch-icon.png` — ícone para iPhone
- `icon-512.png` — ícone padrão do app
- `README.md` — documentação do projeto

## 🌐 Como publicar no GitHub Pages

Suba todos os arquivos deste pacote na raiz do repositório `pele-giuliane`.

Depois acesse:

https://giulianelopes.github.io/pele-giuliane/

## 📲 Como adicionar à tela inicial do iPhone

1. Abra o link no Safari.
2. Toque no botão de compartilhar.
3. Escolha **Adicionar à Tela de Início**.
4. Confirme o nome do app como **Pele Giuliane**.

Se o ícone antigo continuar aparecendo, apague o atalho anterior da tela inicial e adicione novamente pelo Safari.
